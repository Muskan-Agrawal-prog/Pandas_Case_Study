# Pandas_Case_Study
#  Pandas Employee Management Case Study

A beginner-friendly **Pandas case study** focused on analyzing employee management data using Python. This project demonstrates practical DataFrame operations, filtering, sorting, grouping, calculated columns, and basic HR insights.

##  Project Overview

This case study uses an employee dataset containing information such as:

* Employee ID
* Name
* Age
* Gender
* Department
* City
* Experience
* Salary
* Performance Score
* Attendance
* Projects
* Employment Status

The project starts with basic Pandas operations and gradually moves toward employee analysis and HR-related insights.

##  Objectives

The main objectives of this project are to practice:

* Creating and working with Pandas DataFrames
* Reading CSV files
* Selecting rows and columns
* Using `loc[]` and `iloc[]`
* Performing statistical calculations
* Filtering data using conditions
* Applying multiple conditions
* Sorting data
* Creating new columns
* Counting unique values
* Performing `groupby()` analysis
* Finding top and bottom performers
* Extracting basic HR insights
